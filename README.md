# Llightbulb

Llightbulb es un proyecto muy sencillo que fue implementado para una práctica de desarrollo web en mis inicios en el frontend.

## Descripción

Es un proyecto muy sencillo, que se basa en cambiar atributos HTML mediante JavaScript. Simplemente es un par de botones que "prenden" y "apagan" una bombilla virtual. 
Fue creado en una práctica de desarrollo frontend en el 2022.

Puede ser accesado mediante el link https://luisorduran.github.io/Llightbulb/
