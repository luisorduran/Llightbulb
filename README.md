#Llightbulb

Llightbulb is a simple project developed as part of a web development exercise during my early days as a frontend developer.

##Description

This is a very simple project based on manipulating HTML attributes using JavaScript. It consists of a couple of buttons that turn a virtual light bulb on and off.

It was created as part of a frontend development exercise in 2022.

You can access the project here: https://luisorduran.github.io/Llightbulb/
