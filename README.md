# Llightbulb 💡

This is a small project I made back in 2022 while learning frontend development.

## Description

The project is a simple example of how JavaScript can be used to change HTML elements and their attributes.

It has two buttons: one to turn the light bulb on and another to turn it off.

It was a small exercise to practice using JavaScript and understand how it interacts with HTML.
